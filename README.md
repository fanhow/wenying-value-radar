# 穩盈價值雷達（WenYing Value Radar）

穩盈基金的透明估值研究工具。輸入台股或美股代碼即可取得模型公允價值，也能一次匯入多張「方舟運算」手機截圖，辨識名單後批次建立估值。

## 成立初衷

我們不是賭徒。穩盈基金希望用有紀律、可驗證的方法管理共同資金，先守住風險，再追求成長。

- 投資，不是下注：以資料、估值與可承受的風險為基礎
- 多重方法驗證：方舟運算找機會、日本蠟燭圖判讀節奏、公允價值確認安全邊際
- 風險放在報酬之前：先決定可承受的損失，再決定投入金額
- 順勢選擇優質標的：尊重市場方向，研究基本面良好且具成長潛力的股票與基金

## 主要功能

- 股票代碼搜尋：台股例如 `2330`、`3508`；美股例如 `AAPL`、`AMD`
- 方舟截圖匯入：支援 PNG、JPG、WebP，一次最多 12 張
- 多模型透明估值：CAPM／WACC、5 年與 10 年 DCF、P/E、P/B、P/FCF、EV 倍數、EPV、Graham 與適用時的 DDM
- 結構性趨勢快照：AI 基礎設施、太空經濟、人口老化與醫療、電網與電氣化、網路安全、機器人與自動化；按月檢視官方來源
- 模型資料不足時自動排除，不以示範數字補空白
- ETF 以方舟畫面中的即時淨值（iNAV）作參考，並警示槓桿／反向 ETF
- 觀察清單與研究資料保存在使用者的瀏覽器
- 個股可手動更新公開資料，也可自行輸入估值假設

## 資料來源

| 市場／資料 | 來源 | 用途 |
|---|---|---|
| 台灣上市 | TWSE OpenAPI | 收盤價、本益比、股價淨值比、代碼核對 |
| 台灣上櫃 | TPEx OpenAPI | 收盤價、本益比、股價淨值比、代碼核對 |
| 美國財報 | SEC EDGAR XBRL APIs | LTM／年度 EPS、淨值、現金流、營收、EBIT、EBITDA、現金與有息負債 |
| 美國價格 | Nasdaq 市場資訊 | 最近可取得的市場價格 |
| 方舟截圖 | 使用者裝置內辨識 | 股票代碼、截圖價格、ETF 即時淨值 |

原始截圖只在瀏覽器內進行 OCR，不會上傳；伺服器只收到辨識後的文字，以便與交易所及 SEC 名錄核對。

## 估值方法

系統會先依產業、成長階段、配息率及資料完整度檢查模型是否適用，再將通過檢查的模型作簡單等權平均。股權自由現金流 DCF 使用 CAPM 股權成本、逐年收斂成長率及悲觀／基準／樂觀情境；WACC 另作資本結構揭露。企業倍數只有在存在獨立且可驗證的倍數時才納入，並加入每股淨負債調節。EPV、DDM、Graham 與金融業 DCF 均設有明確排除條件。

結構性趨勢的成長區間是依 IEA、DOE、ESA、WHO、UN、ENISA、CISA、NIST 與 IFR 等公開資料作出的保守模型推導。它最多只占 DCF 起始成長率 25%，不會直接提高 P/E、P/B、EV 倍數或給予題材溢價；公司仍須具有正數 EPS、自由現金流及足夠財務資料才會套用。

異常模型只依其他適用模型的分布判斷，不使用目前股價決定是否納入，因此改變股價只會改變估值差距，不會反過來改變企業公允價值。資料仍是年度快照、欄位完整度不足或模型分歧較大時，系統會降低信心並揭露排除原因。模型價格是研究起點，不是單獨的買賣指令。

## 部署說明

這是包含伺服器 API 的全端網站，不能只用純靜態 GitHub Pages 執行完整功能。GitHub 用於公開保存及協作原始碼；正式網站需部署到可執行伺服器端路由的平台。

若以 GitHub 網頁介面更新儲存庫，可直接解壓本專案 ZIP，再將資料夾內的檔案拖曳到儲存庫根目錄。請勿把 ZIP 本身當成唯一檔案上傳，否則 GitHub 不會展開其中的程式碼。

## 重要聲明

本專案僅供投資研究與教育用途，不構成投資建議、招攬或報酬保證。公開資料可能延遲、缺漏或因公司申報方式不同而無法比較，使用者在交易前仍應查核最新公告、財報與風險。

「方舟／ARKER」名稱與圖標屬其原權利人；本專案為穩盈基金的獨立研究工具，並非方舟官方網站或服務。
