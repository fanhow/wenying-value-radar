# 台股 P/B－LTM ROE 留出研究結果

2026-09-21；事前規格：`taiwan-pb-roe-study-protocol-20260921.md`。27項合成測試及獨立檢查通過後，主代理首次執行真實資料。沒有調整已固定seed、ROE桶、至少五家或IQR門檻。

## 決策：暫不接入正式估值

B在共同223檔的平均絕對log誤差由0.601992降為0.542132，中位數由0.426070降為0.398903；126改善、87惡化、10不變。但覆蓋由271/272（99.63%）降為223/272（81.99%），48檔A有值而B棄權。不同產業與ROE區間有反例，沒有充分證據把分桶改動立即套用正式排行榜。

這是在**同一截面解釋市場P/B**，不是與外部FV比準確率，更不是內在價值、投資報酬、前瞻ROE或跨時間驗證。原cohort早已被接觸，只有本次估計的ticker-proxy訓練／測試分離；不能稱為完全盲測。結果揭露後再改規格，這批holdout也已成開發資料，不能冒充新的獨立驗證。

- Secondary business-group panel為0：現有memory群已在discovery清單。保留空組與null指標，不從industry借樣本填補。
- ROE<=0組共有57檔，均為負值，零值0；負ROE並未轉成0或無限PB。

主要統計只比較同時A/B有值的相同公司，不拿A全部271檔與B的223檔直接比平均。指標為 `abs(log(predictedPB/observedPB))`，越小表示更接近當下市場P/B；**不是百分比誤差**。
